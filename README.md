# Yoxi 車車 — 養成型叫車 App 原型

一個可以直接在瀏覽器打開試玩的互動原型。車車站在你們跑過的路線上；
它知道你今天還要去哪、幾點該出門，也會在你難得有空的晚上丟一個盲盒約會給你。

**沒有要坐車的人也能玩。** 這是一個 IP，不是一張叫車表單：

- 車車每天自己在外面發生一件事（被鳥大便、跟隔壁特斯拉互看、幫落葉讓位），打開就聽得到
- 停車場那排都是同事，它會轉述**隔壁那台**說了什麼——包括上一句誇對方收藏、下一句說都是 A 貨
- 它會**洞察你**：「你叫我的時候通常已經遲到了」「你說沒事的那幾天，路線都特別長」
- 它會生氣，生氣就要**哄**（對不起啦／秀秀／幫你買新掛件／那我先走了）；三天沒搭車它會**心碎**
- 它會**自己開口要改名字**，也會情勒你幫它升級 premium
- 連續來看它，它自己算天數並且嘴你
- 名字按骰子亂取，造型的名字沒有一個是正經的

**打開方式**：用瀏覽器開 `index.html` 就好，沒有 build、沒有相依套件。

分頁只有四個，每頁最多三塊：

- **車庫**（首頁）：車車、預約。就這兩件事（有行程在跑的時候多一條可以點進去取消的狀態列）。加工不放入口——分頁上本來就有
- **行程**：下一站、常跑地點、今天
- **日誌**：一頁日記——日期戳、路線圖、三個數字、車車一句話、當天的時間軸與撿到的貼紙
- **加工**：上方固定顯示車車，下方分段切換造型／配件／聯名

首頁刻意不放摸摸／洗車／充電／聊天那類按鈕——那是為了玩而玩的互動，
親密度本來就只由真實搭車餵養，按鈕沒有存在的理由。

## 設計前提：使用者是誰

yoxi 的常客多半不是在觀光，是趕路的人——乙方要去客戶那邊、自由接案的要在工作室與客戶之間移動、
上班族趕著打卡。所以首頁只做三件事：看車車、預約下一趟、去加工。預約卡只留最少的必要資訊——
幾點抵達、車程幾分鐘、幾點該出門、還剩幾分鐘。剩 15 分鐘以內，倒數轉紅、
CTA 換成「馬上叫車」，車車的語氣也從「你慢慢來」轉成「你要跑一下」。

原型左側的「使用者情境」可以切換三種人，行程、常跑地點、路線圖與文案重點都會跟著換。

## 核心循環：參考皮克敏 Bloom

皮克敏 Bloom 最強的一步是「資源＝你本來就會做的事」——走路長皮克敏，不用為了玩而多做什麼；
撿到的皮克敏會依地點戴不同裝飾；一天結束自動生成日記。這個原型把同一套結構搬到叫車上：

| 皮克敏 Bloom | 這裡 |
| --- | --- |
| 走路的步數 | **搭車的里程與趟數**——親密度只由真實搭車餵養，摸摸洗車只影響心情 |
| 依地點取得的裝飾 | **地點紀念品**——去客戶端帶回識別證吊牌、去超商帶回中獎發票，可以掛到車上 |
| 每日回顧 Lifelog | **行車日誌**——今天跑了哪些路、車車對每一趟的碎念、帶回什麼 |
| 皮克敏跟著你走 | 車車站在你們一起跑過的路線圖上，今天的路線是綠色的 |

所以循環是：**去了地方 → 帶東西回來 → 晚上結算成一頁故事 → 隔天想再看**。

## 原型涵蓋的功能

| 功能 | 說明 |
| --- | --- |
| 路線地圖 | 每趟叫車與每次盲盒約會都畫上地圖。工作路線走藍色系、約會路線走暖色系，點地圖或清單切換要看哪一條 |
| 下一站 | 依情境給出下一個行程、建議出發時間與倒數；急迫時整張卡片與 CTA 都會換掉 |
| 今天的安排 | 一整天的行程清單，已過的淡出 |
| 常跑地點 | 一鍵指定臨時目的地，車車會針對那個地點回話 |
| 叫車 | 完整的叫車流程：出發地來自定位、目的地可以打字或從常跑地點／今天的行程／收起來的約會裡挑、選車型（一般／大車／寵物）、看預估車資與車程，然後叫車。媒合中 → 司機接單 → **看著它開過來**（小地圖上是你自己那台車，沿著街廓一段一段靠近「你在這」那根 pin，ETA 每 1.1 秒少一分鐘，到 0 就變成「車到了，在門口」）→ 我上車了 → **行程中**（進度條、剩幾分鐘、車車碎念）→ 抵達。**任何階段都能取消**，首頁也一直看得到進行中的行程。**有一趟在跑的時候叫不了第二台**——首頁與行程頁的 CTA 都變成「查看進行中的行程」，收起來的約會按「約這趟」也會直接開那一趟 |
| 加購送虛寶 | **上車之後才問**——車還沒到就先問要不要加錢，順序是反的。請司機喝一杯（+30）、走風景那條路（+50，多繞 2 km，剩餘車程會跟著加）。加購的回饋是**保證給**的紀念品，不看平常的掉落機率，抵達時直接開給你看 |
| 聯名／廣告活動 | 加工頁多一段「聯名」：三檔活動（兩檔聯名、一檔廣告主投放），各有檔期、主視覺色與獎勵階梯——搭滿幾趟拿掛件、再滿拿造型或折價券。進度就是「參加之後又搭了幾趟」，不加權、不會超過目標；全部領完整張卡變成「已完成」。**合作對象全部是虛構的**，欄位就是正式接檔要填的東西 |
| 定位 | 按下去會真的跟瀏覽器要定位權限。拿到就是「已開啟」；被拒絕或環境不支援，會明講原因並給一個「用示範定位繼續」，兩種狀態在畫面上分得出來。沒開定位就不能叫車——出發地不知道在哪 |
| 模擬定位 | 開啟定位之後，左側示範台可以指定車車現在停在哪，叫車的出發地與行程頁的常跑地點會跟著換 |
| 個性＝那台車 | 個性綁在造型上，而且**沒有個性欄位**——不寫「這台是溫柔療癒型」，直接讓每台車在造型卡上講一句話，聽得出來就認得出來。上線引導的第二步也一樣：三台車，各說一句，選一台就好。六種人格（暖暖／小辣／阿嘿／老派／霧霧／尬彼）換車就換，性格參數跟著回到那台的基準；那組參數是內部狀態，收在左側後台，不對使用者顯示 |
| 尬彼（迷因車） | 網路廢話型。「484 想出門？送啦」「起來了喔？我還以為你芭比Q了」「下班了沒？沒有的話我幫你按離職單」。對應造型是**尬彼機彼**，車頭貼滿 484／笑死／送啦的歪貼紙 |
| 個性 | 十種，綁在造型上：暖暖／小辣／阿嘿／老派／霧霧／尬彼／**霸總**（惜字如金）／**姐姐**（罩你，不問第二次）／**茶茶**（茶裡茶氣，都說沒關係）／**大聲公**（社交恐怖分子）。十種都寫滿了首頁台詞、推播、點車車、摸摸洗車充電、說點什麼、下一站、撿到東西、抵達、叫車全流程、日誌、盲盒。「寶貝～～～」不是一種個性，是櫻花那台的口頭禪 |
| 個性漂移 | 黏人／毒舌／話癆／浪漫四條參數，隨互動時段與頻率自己移動 |
| 哄車車 | 它真的會生氣，所以也要真的哄得回來。生氣或心碎的時候，「說點什麼」會變成**「哄一下」**：對不起啦／秀秀／回頭幫你買新的掛件／……那我先走了。最後一個會讓它更氣，前面三個各有九種個性的回答 |
| 心碎 | 三天沒搭車，心情變成**心碎中**、臉是哭的、按鈕變哄一下，台詞換成十種個性各自的版本。搭一趟就重新計時。**例外：霸總不會哭**——再難過臉也只是繃緊，心情列寫「……沒事」，只講「幾天了。」 |
| 爆嗆 | 連戳超過八下不再只是「夠了喔」，會進到**爆嗆**那層：「你484很喜歡被罵」「我開始擔心的不是我，是你」 |
| 它看得出你是故意的 | 一直挑紅色的話題、在它已經在氣的時候還一直戳、哄它還選「那我先走了」——這些會**累積成一個數字**，分成三段：<br>**第一段（3 次）**它開始懷疑，偶爾丟一句「……你是不是故意的」<br>**第二段（7 次）**它直接講破，十種個性各一句：「484 喜歡被罵。承認吧。」「恕我直言，您似乎享受被責備。」「有些人惹別人生氣，是為了確認自己被在乎。」<br>**第三段（12 次）**它決定配合演出：心情列直接變成**「在嗆你」**、臉是得意的、首頁 40% 機率**先開口嗆你**（「你今天又來討罵了」「我很閒。你要幾句。」「今天要嗆哪個部分，你點菜」）、戳四下就進爆嗆而不是八下<br>**一天不惹它就消兩點**，幾天沒惹它會自己退回去，不是一去不回的狀態 |
| 隔壁那台 yoxi | 停車場那排都是同事。15 則八卦：它會轉述、會比較、上一句誇對方的收藏下一句說都是 A 貨、會拿隔壁升級 premium 情勒你，也會把你的事講出去。「說點什麼」裡有一個話題就是問它隔壁說了什麼 |
| 收回訊息 | 講完偶爾自己後悔，泡泡會變成「車車收回了一則訊息」。它說升級 premium 就能無痕——**答應了它會說「開玩笑的啦，這裡沒有金流」**，之後收回會標上（無痕）|
| 洞察人心 | 12 句它自己觀察到的事，不是報數字：「你叫我的時候通常已經遲到了。所以我現在都提前五分鐘出門。」「你不是不想回家，你是還沒準備好進門。我可以再繞一圈。」跑滿四趟才會開始講 |
| 車車自己要改名 | 名字不是只有你能取。跑過一趟或連續來過，它就有機會在首頁開口（一天最多一次），泡泡下面直接給好啊／不行。有些名字是看你的資料想的（最常去的地點、連續天數、累積公里、掛了幾件） |
| 越高級越閃 | 等級到 3 旁邊三顆星星、4 是四顆、5 以上六顆，一顆一顆錯開時間眨。位置全部避開車身輪廓 |
| 公益活動 | 第四檔活動是**公益**：不多收你的錢，你跑滿了對方那邊收到一份物資。獎勵是公益別針與**身經百戰**造型（刮痕都留著，OK 繃、幾道刮痕、一枚別針）。合作對象一樣是虛構的 |
| 造型 | 17 款外觀，名字一律不正經：**財富自由車／沒有你的笑話冷／霸總／7p7p+8+8／時速三十／整台在發光／櫻花掉不停／鹿角是租的／半糖去冰／自稱九尾狐／恭喜發財龍／歸剛欸／姐姐罩你／大拇指／茶裡茶氣／停車場之聲**，加上公益活動才拿得到的**身經百戰**。基本款直接有，季節、聯名、公益款綁等級或活動解鎖；換造型同時換個性、配件與車牌 |
| 每一台自己的口頭禪 | **十七款全部都有**，講的話一定對得上它的名字。財富自由車講股市（「股價都沒我綠」）、沒有你的笑話冷真的講冷笑話（「為什麼冷氣不會考試？因為它只會吹」）、霸總「錢不是問題，問題是你還站在外面」、7p7p+8+8「喵？」「卯貓」「別在那邊貓咪咪」、時速三十「極速我不能講，會嚇到你。……三十」、櫻花掉不停「又掉了三片。我沒有在掉頭皮屑」、鹿角是租的「一月要還」、恭喜發財龍「紅包拿來」、大拇指「專車來按讚」、身經百戰「我不修。修好就沒有故事了」。首頁台詞與點車車都會混進來 |
| 茶裡茶氣 | 專門情勒你買掛件的那台。先示弱、再比較、最後你就會想幫它買點什麼：「沒關係啦～我這樣就好～」「隔壁那台昨天換了新的掛件～很好看～」「你上次說要幫我買～我沒有在等喔～真的～」。連生氣被哄都是「沒關係啦～我本來就沒有在生氣～」|
| 停車場之聲 | 社交恐怖分子那台。八卦的出現機率是別台的七倍多（45% vs 6%），每句話都在轉述：「你知道嗎——」「我今天跟三台講過話。你是第四個。」「先上車，我路上講。」被打斷會生氣：「你一直戳我我沒辦法講話。」|
| 盲盒約會 | **放在地圖上**：車車旁邊會出現一個會呼吸的禮物，上面直接寫著本週還剩幾次。點進去是盲盒頁——大大的次數、三顆點表示用掉幾次、什麼時候補滿、抽過哪幾張，然後才是「開一個」。用完不會把入口藏起來，會變灰並改成「週一補滿」。開箱是全螢幕的——盒子搖晃、爆開、依稀有度變色噴彩帶，然後浮出**一張明信片**。**開出來不會變成預約**：只有「先收起來」與「這次不要」，收起來的會進日誌，要不要真的去是之後按「約這趟」才決定，也可以直接刪掉 |
| 紀念品收藏 | 25 件、7 種地點類型（含 4 件只能從聯名活動拿的活動限定）。**每一件都照實物畫**：識別證有大頭照、發票有紅色中獎章、御飯糰有海苔、拖鞋是藍白拖、塑膠袋是紅白條紋、拉花照片是拍立得裡歪掉的心。不是同一顆球換顏色。搭車有機率帶回，可掛兩件到車上（後照鏡與儀表板），車上與收藏頁共用同一份圖 |
| 行車日誌 | 做成一頁日記，不是一份報告：左上角日期戳、路線圖、**一行**數字（趟數／公里／新收藏，本來是三張大卡片，光那排就吃掉 110px）、車車**一天只講一句**、時間軸（每個地點一個顏色的圓點，那一趟撿到東西就把貼紙貼在那一格）、當天的貼紙牆。「一起跑過的路線」那份清單整段拿掉——地圖上本來就畫著全部 |
| 加工車車 | 造型、掛件、個性收在同一頁，首頁只留一個入口，副標直接顯示目前的組合 |
| 點車車 | 直接點車車就有反應，不透過按鈕。依點到的高度分成車頂／車身／保桿三區，各有台詞；連點四次以上會切換成「被鬧煩了」的一組。會擠壓彈跳、噴粒子，心情與默契上升 |
| 跟它說話 | 車車旁的「說點什麼」只留**六句**，字都很短：你在幹嘛／隔壁那台呢／謝謝你／你今天好看，最後兩句是紅的——我想坐保時捷／我想換 app。踩到紅的它會真的生氣：車體晃動、表情變臭、心情大跌，鬧脾氣 14 秒才恢復。顏色跟順序已經分得出安不安全，所以不另外寫分區標題 |
| 裝備位 | 上面三個位子當切換：**掛件**（後照鏡）、**擺飾**（儀表板）、**輪胎**（四個輪子，六款鋼圈依等級解鎖），每格直接標出裝在哪、現在裝什麼——不另外寫一段說明文字。點哪一格，下面就只列裝得進那一格的東西，照地點分組一路往下捲。不會出現「隨便點兩個、其中一個莫名其妙吊著」 |
| 明信片 | 開出來的行程不是一張表格，是一張明信片：六種地點各有自己的風景（河堤的夕陽沉進水裡、夜市的紅燈籠與攤棚、超商亮著的招牌、咖啡廳窗邊那杯、辦公大樓夜裡還亮著的那幾格、巷口那盞路燈）、右上角一張有齒孔的郵票（車車頭像＋稀有度）、一枚 YOXI 郵戳，車車那句話當明信片上的字。收起來的在日誌裡也是小張明信片，不是一行清單。收藏那格本來右半邊塞了標題、路線、車資、兩顆按鈕擠成一團——「刪掉」改成明信片左上角一個叉，路線與車資併成同一行，明信片放大到 124px，右邊就只剩標題／一行資訊／一顆「約這趟」三層 |
| 去過的地方 | 日誌的一段收藏：每個去過的地點蓋一個章，章上是去過幾次，底下是累積公里，章的顏色跟著地點類型走。最多列六個，其餘收成一行 |

## 車車的外觀是可以整個換掉的

現在跑的是內建的 WebGL 佔位模型——那是用程式硬刻的幾何（programmer art），
不是建模，所以不會好看。**它只是佔位**。正式資產到位後，改 `index.html` 裡的
`CAR_SOURCE` 一個常數就好，app 其他邏輯完全不用動：

```js
const CAR_SOURCE = { kind: "svg" };     // 目前預設：手繪向量
```

**目前預設是向量版**，不是 3D。手刻幾何的即時 3D 做不出角色設定圖那種質感，
與其擺一個做不好的 3D，不如先用一張畫得乾淨的平面圖；等真的模型到位再切回去。

| kind | 用途 | 設定 |
| --- | --- | --- |
| `frames` | **最推薦**。Blender 離線算好的角度序列 PNG，畫質＝離線算圖、效能＝貼圖，還能拖曳轉動 | `{ kind: "frames", frames: { yoxi: ["a/00.png", …], … } }` |
| `model` | glTF／glb，用 `<model-viewer>` 顯示，自帶 PBR、HDR 環境光、接觸陰影 | `{ kind: "model", glb: { yoxi: "assets/car.glb" } }` |
| `spline` | Spline 場景，設計師自己就能做，質感接近角色設定圖 | `{ kind: "spline", scene: "https://…/scene.splinecode" }` |
| `svg` | 手繪向量，**目前預設**，永遠可用 | `{ kind: "svg" }` |

`model` 與 `spline` 需要先載入各自的 web component script（CSP 環境要自架）。
任何一種初始化失敗都會自動退回 `svg`，不會出現白畫面。

渲染器只需要實作四個方法：`ok()`、`mount(host)`、`set(skin, mood)`、`thumb(skin, key)`。
首頁的大圖、造型縮圖、個性頭像、推播圖示全部走同一個介面。

**外觀選型建議**：提案階段用 Spline（設計師不用寫程式，質感直接到位），
正式產品走 Blender 建模匯出 glTF；若不需要即時旋轉，`frames` 的投報率最高。

## 免費的建模方案

手上有角色設定圖的話，這幾個都免費，由易到難：

- **Womp**（womp.com）：瀏覽器上捏黏土球，天生適合這種圓潤造型，可匯出 glb
- **Meshy／Tripo**：有免費額度，上傳角色設定圖直接生 glb，最短路徑
- **Spline** 免費方案：瀏覽器建模，內建材質與燈光
- **Blender**：完全免費、天花板最高、學習曲線最陡
- **Poly Pizza／Kenney.nl**：CC0 免費模型，抓一台可愛的車改色即可

## 附帶的 WebGL 佔位模型

`kind: "webgl"` 仍然可用，但它是用原生 WebGL 硬刻的幾何（CSP 擋外部 CDN，沒有用 three.js），
屬於佔位性質。
比例照參考圖重建：又短又高的泡泡車，不是長條車。

- **車身**：定義一條側面輪廓（車頂線、車底線、車寬）後沿車長放樣。車頭保留完整的
  正面，再用圓角端蓋收邊，所以有真正的「臉」可以放五官
- **塗裝分層**：車身整台品牌綠，白色下半身與深色車窗各是一片沿同一條輪廓向外偏移
  的曲面殼。邊界由幾何決定而不是著色器猜，所以綠白分界、包覆式車窗、車尾留綠
  都跟參考圖對得上
- **五官定位**：用數值求解找出 (x, y) 落在車頭表面的 z，大頭燈與嘴巴才貼得準
- 有真實光照、鏡面高光、邊緣光與接地陰影；會自己緩慢擺動，也可以用滑鼠拖曳轉動

**不畫臉**。頭燈就是頭燈——圓柱燈碗加品牌綠燈框、白色燈面，不論車身怎麼彎，
燈口都是乾淨的正圓；只在前保桿保留參考圖本來就有的一道微笑，心情靠嘴型微調。
個性表達交給對話與推播，不靠五官。

造型縮圖、個性頭像與推播圖示都是同一個渲染器離屏產生後快取成圖片，所以整個 app
只有一顆會動的 3D 畫布。車庫分頁不在畫面上時會停止渲染。
沒有 WebGL 時自動退回向量版本的車車。

## 作息推論在後台，不在 app 裡

使用者端只會感覺到「它好像知道我幾點該出門」。24 小時開啟熱區、標籤與信心值、推論結果、
自動產生的推播排程，全部收在頁面左側的**營運後台**區塊，用分析口吻書寫；產生出來的推播文案
仍然是車車的口吻，可以直接看到「推論 → 文案」怎麼接起來。

## 展示用控制盤

- **時光滑桿**：把現在時間拉到 0–23 點，介面色溫、車車心情、對話、下一站倒數都會跟著換
- **使用者情境**：乙方跑客戶／自由接案／趕時間上班族
- **平日／週末**：影響後台的週末佔比推論
- **發一則車車推播**：即時看到鎖定畫面推播長什麼樣
- **模擬跑一天**：實際跑四趟，里程、紀念品、日誌與後台熱區會一起長出來
- **模擬定位**：先開啟定位（會真的跳瀏覽器權限），之後可以指定車車現在停在哪
- **清空重養一台**：回到取名與選個性的第一步

## 技術與資料

聯名活動與廣告主的名字、識別、獎勵都是虛構的，只是把欄位跟版位擺出來；正式接檔時整包替換 `CAMPAIGNS` 即可。

單一 `index.html`，原生 HTML／CSS／JS。車車是原生 WebGL 即時 3D，地圖與盲盒是手繪 SVG，
狀態存在 `localStorage`（key：`yoxi.car.v4`）。頁面上有一個 `window.__yoxi` 的小掛勾（`mood()`／`skin()`），只給截圖測試用。亮色主題，所有行程、車資與對話皆為示意內容，
沒有任何連外請求，也沒有任何外部函式庫。

## 待驗證的產品問題

1. 盲盒次數該綁週期、綁乘車次數，還是綁親密度？現在寫死每週 3 次。
1. 叫車取消要不要有次數或費用上限？現在無條件可取消，是刻意的——先讓使用者確定自己不會被綁住。
1. 加購的虛寶保證給，會不會讓平常搭車的掉落顯得沒價值？可能要把加購改成「提高稀有度」而不是「多抽一次」。
1. 聯名活動的進度該不該跨檔期保留？現在是參加當下歸零重算。
1. 拿到新掛件時，位子已經滿了就不會自動裝上——現在是安靜地不裝。要不要主動問「要換掉哪一件」？
2. 紀念品的掉落率（現在 62%）與可掛數量（現在 2 件）需要實測手感。
2. 下一站的資料來源要接行事曆、常用地點學習，還是讓使用者手動排？原型是預設行程。
3. 個性漂移的速度要多快才有感但不失控？現行參數偏保守。
4. 推播頻率上限與靜音時段的預設值尚未定義。
